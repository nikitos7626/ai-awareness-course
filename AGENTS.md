# Инструкции для AI-агентов (AGENTS.md)
**Проект:** Веб-страница образовательного курса «Как работать с AI осознанно»  
**Дизайн-система:** Soft Media Group (SMG)  
**Стек:** Vite + React 19 + TypeScript + Vitest + Playwright

---

## 1. Контекст и назначение проекта
Проект представляет собой интерактивную обучающую веб-страницу для сотрудников компаний без технического образования. Цель — обучить осознанному взаимодействию с AI (подготовка контекста, выбор моделей, делегирование повторяющихся задач в скиллы, безопасное подключение через MCP, двухмодельная верификация и ревью).

## 3. Критические правила работы с кодом для агентов

### 3.1. Дизайн-система и токены SMG
- **Цветовая палитра:**
  - Основной фирменный акцент: `var(--smg-violet)` (`#6228FF`).
  - Основной текст: `var(--smg-ink)` (`#212121`).
  - Фоны: светлые поверхности (`var(--smg-white)`, `var(--smg-gray-50)`), темный фирменный фон (`bg-violet-1.png`).
  - Результаты квиза: успех — `var(--smg-success)` (`#10B981`) и `var(--smg-success-soft)`, ошибка — `var(--smg-danger)` (`#FF6464`) и `var(--smg-danger-soft)`.
  - **Запрещено:** Подменять фиолетовый акцент синим сервисным `--smg-info-500` в основных элементах бренда.
- **Шрифты:**
  - TT Norms Pro и Roboto Flex подключены **локально** из `/fonts/`.
  - **Запрещено:** Подключать сторонние шрифты через Google Fonts или CDN.
- **Масштабирование (Web UI vs Presentation Deck):**
  - Не использовать гигантские слайдовые размеры (26–30px) из презентационных исходников SMG. В веб-интерфейсе базовый текст — 14–16px (`--smg-web-fs-body-md`), заголовки — 22–32px.
  - Высота кликабельных зон на мобильных устройствах — не менее 44px (Touch Target compliance).

### 3.2. Доступность (A11y, WCAG 2.1 AA)
- Все интерактивные кнопки и варианты ответов должны управляться с клавиатуры (`Tab`, `Enter`, `Space`).
- При клавиатурном фокусе обязательно отображать контрастное кольцо `var(--smg-focus-ring-a11y)` (`0 0 0 2px #fff, 0 0 0 4px #6228FF`).
- Блоки пояснений квиза должны иметь атрибут `aria-live="polite"`.

### 3.3. Состояние и хранилище (`localStorage`)
- Ключ хранилища: `smg_ai_course_progress_v1`.
- Любое чтение/запись в `localStorage` обязано оборачиваться в `try/catch` (защита от режима приватного просмотра и поврежденного JSON).
- Прогресс рассчитывается прозрачно по формуле: `(completedTopics + correctQuizzes) / (totalTopics + totalQuizzes) * 100`.

## 4. Команды проверки перед коммитом
Перед отправкой изменений агент обязан выполнить:
1. `npm run build` — проверка отсутствия ошибок TypeScript и сборка бандла.
2. `npm test` — прогон всех модульных и интеграционных тестов Vitest.
3. `npm run test:e2e` — проверка E2E сценариев в Chromium (Desktop + Mobile 360px).
